# System Administration Labs

A collection of practical labs covering Linux administration, Windows Server, system configuration, network services, and system security.

## Topics

- Linux Administration
- Windows Server Administration
- Active Directory
- DNS Server
- DHCP Server
- Users and Groups Management
- File and Folder Permissions
- File Sharing
- System Hardening
- System Troubleshooting

## Tools and Technologies

- Ubuntu Linux
- Windows Server 2019
- VMware Workstation
- Virtual Machines
- PowerShell
- Linux Terminal

## Objectives

- Develop practical system administration skills.
- Configure and manage Windows and Linux environments.
- Understand enterprise system services.
- Apply basic security and troubleshooting techniques.
